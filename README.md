[g9-battle-sprites] (Work In Progress)

A modification for [gen1recomp RBY and GSC] introducing expanded Pokémon graphics, custom menu icon sets, and specialized battle effect overlays.

Note on WIP Status: This mod is currently under active development. Gender-specific sprites and shiny palette integrations are in progress and will be wired into the engine in a future release. Current builds disable or bypass gender/shiny settings.

Features

Expanded Sprite Sets: Gen 1–9 battle sprite support via community resource packs.

Updated UI Icons: Gen 1–9, PLA, and PL-ZA party menu icons.

Custom FX Overlays: Integrated Dynamax cloud effects and Terastal/Crystal texture overlays.
